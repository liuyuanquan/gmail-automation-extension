# 模板管理 Demo

这是一个用于本地调试模板管理功能的 demo 页面。

## 使用方法

### 1. 启动开发服务器

```bash
npm run demo
```

或者使用 vite 直接启动：

```bash
npx vite --config vite.config.js
```

服务器会在 `http://localhost:3000` 启动，并自动打开 demo 页面。

### 2. 访问 Demo 页面

如果服务器没有自动打开，可以手动访问：

- Demo 页面：`http://localhost:3000/demo/index.html`

## 功能说明

### 控制面板

- **打开批量发送对话框**：打开主对话框（在真实环境中会打开 Gmail 撰写视图）
- **打开模板管理**：打开模板管理对话框
- **清除存储数据**：清除所有本地存储的模板配置，恢复到从 GitHub 加载

### 模板管理功能

1. **查看模板列表**：显示所有可用的模板
2. **新增模板**：添加新的邮件模板
3. **编辑模板**：修改现有模板的配置
4. **删除模板**：删除不需要的模板
5. **导出配置**：将当前模板配置导出为 JSON 文件
6. **重新加载**：从 GitHub 强制重新加载模板配置

## 注意事项

1. **Gmail 功能模拟**：由于是本地 demo，Gmail 相关的功能（如打开撰写视图、发送邮件等）会被模拟，不会真正执行。

2. **模板加载**：
   - 模板始终从 GitHub 加载
   - 点击"重新加载"可以强制从 GitHub 加载最新配置

3. **数据持久化**：
   - 模板配置保存在 GitHub 仓库中
   - 可以使用"导出配置"功能备份模板配置
